# 系统架构师论文资料与模板

本目录用于组织系统架构师论文写作的资料、模板与过程产物。按从选题到定稿的阶段化结构，帮助你高效推进与复用。

## 目录结构

- `01-选题`: 选题方向、问题陈述、目标与评审意见
- `02-资料`: 背景资料与参考文献
  - `images`: 原始图片素材
  - `references`: 论文、白皮书、标准、调研报告
- `03-大纲`: 论文大纲与章节结构
- `04-写作`: 正文写作与图表
  - `figures`: 绘图导出（上下文/组件/部署/时序等）
  - `tables`: 表格数据与导出
- `05-评审`: 内外部评审记录、问题清单与改进项
- `06-定稿`: 终稿版本与对外材料
- `templates`: 模板与通用片段

## 快速开始

1. 复制模板：
   - 通用模板位于 `templates/系统架构师论文-万能模板.md`
   - 建议将其复制到 `04-写作/` 并按实际题目命名

2. 放入资料：
   - 背景与参考材料放入 `02-资料/`，原文献入 `02-资料/references/`
   - 图表素材入 `02-资料/images/`

3. 建立大纲：
   - 在 `03-大纲/` 先梳理章节与要点，再展开写作

4. 写作与配图：
   - 在 `04-写作/` 进行正文写作，图表分别放在 `figures/` 与 `tables/`

5. 评审与修订：
   - 在 `05-评审/` 记录评审意见、问题与跟踪状态

6. 归档定稿：
   - 将最终版本与对外发布材料放在 `06-定稿/`

## 推荐工具

- 绘图：Excalidraw、draw.io、PlantUML、Mermaid
- 压测：k6、JMeter、wrk、Locust
- 可观测：Grafana、Prometheus、OpenTelemetry

## 写作建议

- 以问题与价值为导向：说明“为什么做”和“做了有什么价值”
- 数据驱动：使用真实指标（QPS、P99、可用性、成本）
- 决策可追溯：记录关键 ADR 和权衡
- 质量属性具体化：将 NFR 写成可验证的场景
- 图表先行：优先画清上下文、组件、部署、时序图
