### 1.3 预算与约束建模与求解

#### 技术要点
**约束建模：**

1. **带宽预算约束**
   ```
   Σ size(resource_i) · x_i ≤ B_bandwidth
   
   其中：
   - B_bandwidth = f(network.downlink, network.saveData, battery.level)
   - saveData=true 时，B_bandwidth *= 0.3
   - battery < 0.2 时，B_bandwidth *= 0.5
   ```

2. **CPU预算约束**（针对解压/解析成本高的资源）
   ```
   Σ cpu_cost(resource_i) · x_i ≤ B_cpu
   
   cpu_cost(resource) = {
     'js': size * 0.8,      // JS需要解析执行
     'image': size * 0.2,   // 图片需要解码
     'css': size * 0.3
   }
   ```

3. **存储预算约束**
   ```
   Σ size(resource_i) · is_cached(i) ≤ B_storage
   
   B_storage = min(quota.available, 100MB)  // Cache API配额
   ```

4. **隐私与权限约束**（硬约束）
   ```
   if (resource.privacyLabel.includes('PII') && !user.consent) {
     x_resource = 0  // 禁止预取
   }
   
   if (resource.crossOrigin && !resource.cors) {
     x_resource = 0  // 无法缓存
   }
   ```

**决策变量定义：**
```
x_i ∈ {0, 1, 2, 3}  表示资源i的预取等级

0: 不预取
1: 低优先级（延后预取，空闲时）
2: 中优先级（正常预取）
3: 高优先级（立即预取，关键路径）

每个等级对应的属性：
Level 0: -
Level 1: {startTime: 'idle', ttl: 3600, priority: 'low', concurrency: 1, retry: 1}
Level 2: {startTime: 'immediate', ttl: 1800, priority: 'normal', concurrency: 3, retry: 2}
Level 3: {startTime: 'immediate', ttl: 600, priority: 'high', concurrency: 5, retry: 3}
```

**目标函数：**
```
maximize: Σ_route P(route) · Σ_resource u(resource|route) · benefit(x_resource)

benefit(x) = {
  0: 0,
  1: 0.3 * latency_saved,
  2: 0.7 * latency_saved,
  3: 1.0 * latency_saved
}

latency_saved = resource.size / network.downlink  // 简化模型
```

    # 计算效用密度

### 1.4 Service Worker 执行与动态调度

#### 技术要点
**Service Worker架构：**
```javascript
// sw.js 核心模块

class PrefetchScheduler {
  constructor() {
    this.queue = new PriorityQueue();
    this.running = new Map();
    this.cache = await caches.open('prefetch-v1');
    this.sharedChannel = new BroadcastChannel('prefetch-coord');
  }
  
  async executePlan(plan) {
    for (let task of plan) {
      this.queue.push({
        url: task.url,
        priority: task.level,
        ttl: task.ttl,
        retryPolicy: task.retry,
        controller: new AbortController()
      });
    }
    
    this.pump();  // 启动并发下载
  }
  
  async pump() {
    while (!this.queue.isEmpty() && this.running.size < this.maxConcurrency) {
      let task = this.queue.pop();
      this.running.set(task.url, task);
      
      this.fetchWithRetry(task)
        .then(() => this.onSuccess(task))
        .catch(() => this.onFailure(task))
        .finally(() => {
          this.running.delete(task.url);
          this.pump();
        });
    }
  }
}
```

**优先队列实现：**
- 数据结构：最小堆（按优先级+插入时间）
- 动态调整：网络状态变化时重新排序
- 抢占策略：高优先级任务可中断低优先级

**退避与抖动策略：**
```javascript
async fetchWithRetry(task, attempt = 0) {
  try {
    let response = await fetch(task.url, {
      signal: task.controller.signal,
      priority: task.priority  // Chrome 101+
    });
    
    if (!response.ok) throw new Error('HTTP ' + response.status);
    
    await this.cache.put(task.url, response.clone(), {
      metadata: { ttl: task.ttl, timestamp: Date.now() }
    });
    
  } catch (error) {
    if (attempt < task.retryPolicy.maxRetries) {
      // 指数退避 + 随机抖动
      let delay = Math.min(1000 * Math.pow(2, attempt), 10000);
      delay += Math.random() * 1000;  // ±1s抖动
      
      await sleep(delay);
      return this.fetchWithRetry(task, attempt + 1);
    }
    throw error;
  }
}
```

**SWR（Stale-While-Revalidate）实现：**
```javascript
async handleFetch(request) {
  let cached = await this.cache.match(request);
  
  if (cached) {
    let metadata = await this.getMetadata(request.url);
    let age = Date.now() - metadata.timestamp;
    
    if (age < metadata.ttl) {
      // 新鲜，直接返回
      return cached;
    } else if (age < metadata.ttl * 2) {
      // 陈旧但可用，后台刷新
      this.revalidate(request);
      return cached;
    }
  }
  
  // 缓存未命中或过期，网络请求
  return fetch(request);
}
```

**动态TTL计算：**
```javascript
function computeTTL(resource, context) {
  let baseTTL = resource.defaultTTL || 1800;  // 30分钟基准
  
  // 因子1：路由概率（概率高→TTL长）
  let probFactor = Math.sqrt(context.routeProbability);
  
  // 因子2：网络质量（弱网→TTL短，避免陈旧）
  let networkFactor = context.network.rtt < 200 ? 1.0 : 0.5;
  
  // 因子3：缓存压力（存储紧张→TTL短）
  let storageFactor = context.storage.usage < 0.8 ? 1.0 : 0.6;
  
  // 因子4：重试次数（多次失败→TTL短）
  let retryPenalty = Math.pow(0.8, resource.failureCount);
  
  return baseTTL * probFactor * networkFactor * storageFactor * retryPenalty;
}
```

**反事实评估（Counterfactual Evaluation）：**

问题：如何评估"如果采用策略B而非策略A，收益会是多少？"

方法：重要性采样（Importance Sampling）
```python
# 已执行策略A，产生日志数据
# 想评估策略B的期望收益

def counterfactual_estimate(logs, policy_A, policy_B):
    total_reward = 0
    total_weight = 0
    
    for log in logs:
        # 计算重要性权重
        prob_A = policy_A.get_probability(log.action | log.context)
        prob_B = policy_B.get_probability(log.action | log.context)
        weight = prob_B / prob_A
        
        # 加权累积
        total_reward += weight * log.reward
        total_weight += weight
    
    return total_reward / total_weight
```

双稳健估计（Doubly Robust）：
```python
def doubly_robust_estimate(logs, policy_B, reward_model):
    estimate = 0
    
    for log in logs:
        # 直接法：模型预测奖励
        predicted = reward_model.predict(log.context, log.action)
        
        # 逆倾向加权：修正偏差
        if log.action == policy_B.select(log.context):
            weight = 1 / policy_A.get_probability(log.action | log.context)
            correction = weight * (log.reward - predicted)
        else:
            correction = 0
        
        estimate += predicted + correction
    
    return estimate / len(logs)
```

   # training/distill.py
   import torch
   import torch.nn as nn
   
   class StudentModel(nn.Module):
       def __init__(self, vocab_size, embed_dim=128, hidden_dim=256):
           super().__init__()
           self.embed = nn.Embedding(vocab_size, embed_dim)
           self.lstm = nn.LSTM(embed_dim, hidden_dim, batch_first=True)
           self.fc = nn.Linear(hidden_dim, vocab_size)
       
       def forward(self, x):
           embeds = self.embed(x)
           _, (h, _) = self.lstm(embeds)
           return self.fc(h[-1])
   
   def distill_loss(student_logits, teacher_logits, hard_labels, temperature=2.0, alpha=0.5):
       # 软标签：从教师模型学习
       soft_loss = nn.KLDivLoss()(
           F.log_softmax(student_logits / temperature, dim=1),
           F.softmax(teacher_logits / temperature, dim=1)
       ) * (temperature ** 2)
       
       # 硬标签：从真实标签学习
       hard_loss = nn.CrossEntropyLoss()(student_logits, hard_labels)
       
       return alpha * soft_loss + (1 - alpha) * hard_loss
   ```

   // src/solver/greedy.ts
   export class GreedySolver {
     solve(resources: Resource[], budget: Budget, predictions: Prediction[]): Plan {
       // 计算每个资源的效用密度
       const scored = resources.map(r => ({
         resource: r,
         density: this.computeDensity(r, predictions, budget)
       }));
       
       // 按密度排序
       scored.sort((a, b) => b.density - a.density);
       
       // 贪心选择
       const plan: Plan = [];
       let usedBandwidth = 0;
       let usedCpu = 0;
       
       for (const { resource, density } of scored) {
         const cost = this.computeCost(resource, budget);
         
         if (usedBandwidth + cost.bandwidth <= budget.bandwidth &&
             usedCpu + cost.cpu <= budget.cpu) {
           
           plan.push({
             url: resource.url,
             level: this.decideLevel(resource, predictions),
             ttl: this.computeTTL(resource, predictions),
             priority: resource.priority
           });
           
           usedBandwidth += cost.bandwidth;
           usedCpu += cost.cpu;
         }
       }
       
       return plan;
     }
     
     private computeDensity(resource: Resource, predictions: Prediction[], budget: Budget): number {
       // 效用 = Σ P(route) * u(resource|route)
       let utility = 0;
       for (const pred of predictions.predictions) {
         const resScore = pred.resources.find(r => r.url === resource.url);
         if (resScore) {
           utility += pred.probability * resScore.utilityScore;
         }
       }
       
       // 成本 = 带宽 + CPU（归一化）
       const cost = resource.size / budget.bandwidth + 
                    this.estimateCpuCost(resource) / budget.cpu;
       
       return utility / cost;
     }
   }
   ```

   ```typescript
   // src/sw/priority-queue.ts
   class PriorityQueue<T> {
     private heap: Array<{ priority: number; item: T }> = [];
     
     push(item: T, priority: number) {
       this.heap.push({ priority, item });
       this.bubbleUp(this.heap.length - 1);
     }
     
     pop(): T | undefined {
       if (this.heap.length === 0) return undefined;
       
       const top = this.heap[0];
       const bottom = this.heap.pop()!;
       
       if (this.heap.length > 0) {
         this.heap[0] = bottom;
         this.sinkDown(0);
       }
       
       return top.item;
     }
     
     private bubbleUp(index: number) {
       while (index > 0) {
         const parentIndex = Math.floor((index - 1) / 2);
         if (this.heap[index].priority <= this.heap[parentIndex].priority) break;
         
         [this.heap[index], this.heap[parentIndex]] = [this.heap[parentIndex], this.heap[index]];
         index = parentIndex;
       }
     }
     
     private sinkDown(index: number) {
       while (true) {
         const leftChild = 2 * index + 1;
         const rightChild = 2 * index + 2;
         let largest = index;
         
         if (leftChild < this.heap.length && this.heap[leftChild].priority > this.heap[largest].priority) {
           largest = leftChild;
         }
         if (rightChild < this.heap.length && this.heap[rightChild].priority > this.heap[largest].priority) {
           largest = rightChild;
         }
         
         if (largest === index) break;
         
         [this.heap[index], this.heap[largest]] = [this.heap[largest], this.heap[index]];
         index = largest;
       }
     }
   }
   ```

2. 调度器主循环
   ```typescript
   // src/sw/scheduler.ts
   export class PrefetchScheduler {
     private queue = new PriorityQueue<PrefetchTask>();
     private running = new Map<string, AbortController>();
     private maxConcurrency = 3;
     
     async executePlan(plan: Plan) {
       for (const task of plan) {
         this.queue.push(
           {
             url: task.url,
             ttl: task.ttl,
             retryPolicy: { max: 3, delay: 1000 }
           },
           task.level  // 优先级
         );
       }
       
       this.pump();
     }
     
     private async pump() {
       while (!this.queue.isEmpty() && this.running.size < this.maxConcurrency) {
         const task = this.queue.pop();
         if (!task) break;
         
         const controller = new AbortController();
         this.running.set(task.url, controller);
         
         this.fetchWithRetry(task, controller.signal)
           .then(() => console.log(`预取成功: ${task.url}`))
           .catch(err => console.warn(`预取失败: ${task.url}`, err))
           .finally(() => {
             this.running.delete(task.url);
             this.pump();
           });
       }
     }
     
     private async fetchWithRetry(task: PrefetchTask, signal: AbortSignal, attempt = 0): Promise<void> {
       try {
         const response = await fetch(task.url, { signal });
         
         if (!response.ok) {
           throw new Error(`HTTP ${response.status}`);
         }
         
         await this.cacheResponse(task.url, response, task.ttl);
         
       } catch (error) {
         if (attempt < task.retryPolicy.max) {
           const delay = task.retryPolicy.delay * Math.pow(2, attempt) + Math.random() * 1000;
           await this.sleep(delay);
           return this.fetchWithRetry(task, signal, attempt + 1);
         }
         throw error;
       }
     }
     
     private async cacheResponse(url: string, response: Response, ttl: number) {
       const cache = await caches.open('prefetch-v1');
       const cloned = response.clone();
       
       // 附加元数据
       const metadata = {
         timestamp: Date.now(),
         ttl: ttl,
         url: url
       };
       
       await cache.put(url, cloned);
       await this.saveMetadata(url, metadata);
     }
   }

     compute(resource: Resource, context: RuntimeContext): number {

       const factors = {
         probability: Math.sqrt(context.routeProbability),

   # backend/evaluation/counterfactual.py
   import numpy as np
   from typing import List, Dict
   
   class CounterfactualEvaluator:
       def evaluate(self, logs: List[Dict], candidate_policy: Policy) -> float:
           """重要性采样估计候选策略的期望收益"""
           total_reward = 0
           total_weight = 0
           
           for log in logs:
               # 计算重要性权重
               action_prob_logging = log['action_probability']
               action_prob_candidate = candidate_policy.get_probability(
                   log['context'],
                   log['action']
               )
               
               weight = action_prob_candidate / (action_prob_logging + 1e-8)
               
               # 加权奖励（避免极端权重）
               capped_weight = min(weight, 10.0)
               total_reward += capped_weight * log['reward']
               total_weight += capped_weight
           
           return total_reward / total_weight if total_weight > 0 else 0
       
       def grid_search_thresholds(self, logs: List[Dict]) -> Dict:
           """网格搜索最优阈值"""
           best_config = None
           best_score = float('-inf')
           
           for bandwidth in [50, 100, 200, 500]:  # KB
               for threshold in [0.5, 0.6, 0.7, 0.8]:
                   config = {
                       'bandwidth_budget': bandwidth * 1024,
                       'probability_threshold': threshold
                   }
                   
                   policy = self.build_policy(config)
                   score = self.evaluate(logs, policy)
                   
                   if score > best_score:
                       best_score = score
                       best_config = config
           
           return best_config
   ```

## 三、关键风险与应对

### 风险1：大模型推理延迟过高
**影响**：超过500ms会阻塞预取计划生成

**应对**：
1. 端侧模型优先，云侧作fallback
2. 异步预测，不阻塞页面渲染
3. 缓存历史预测结果（相似上下文复用）

---

### 风险2：Service Worker兼容性问题
**影响**：Safari/Firefox部分API不支持

**应对**：
1. 特性检测 + 优雅降级
   ```typescript
   if ('serviceWorker' in navigator) {
     // 启用预取
   } else {
     // 降级到传统预加载
   }
   ```
2. Polyfill关键API（BroadcastChannel等）

---

### 风险3：隐私合规风险
**影响**：预取敏感资源可能违反GDPR/CCPA

**应对**：
1. 隐私标签强制校验
2. 用户同意机制（Cookie Banner）
3. 定期隐私审计

---

### 风险4：成本超预算
**影响**：云端LLM调用成本过高

**应对**：
1. 端侧模型承载90%+流量
2. 云侧请求限流（Rate Limiting）
3. 批量请求（攒10个预测一起调用）
