## 💡 使用建议

### 考前准备（建议3周）

**第1周：熟悉内容**
- 通读7篇论文各3遍
- 理解每篇论文的结构和逻辑
- 记录关键技术点和数据

**第2周：记忆强化**
- 熟记每篇论文的摘要部分
- 记住核心的量化指标
- 理解架构设计的权衡点

**第3周：模拟演练**
- 手写模拟完整论文（计时）
- 练习段落划分和字数控制
- 准备应变策略

### 考试应对

#### 1. 审题策略（5-10分钟）
- 明确题目要求的架构类型
- 识别题目关键词
- 快速定位使用哪篇论文

#### 2. 写作策略（105分钟）
- 摘要：10分钟（200字）
- 正文9段：95分钟（每段10分钟）
- 保持段落清晰，字迹工整

#### 3. 检查策略（5分钟）
- 检查字数是否达标
- 检查数据前后是否一致
- 检查有无明显错误

### 临场应变

**如果题目不在准备范围：**
1. 找最接近的论文套用
2. 调整论文侧重点
3. 保证架构合理性和逻辑完整性
4. 多用量化数据证明效果

**套用技巧：**
- AI大模型 → 可以套用云原生或微服务架构
- 信创国产化 → 可以套用云原生架构改造
- 中台架构 → 套用微服务架构突出能力复用
- 安全架构 → 任意论文扩展安全设计部分
- Serverless → 套用云原生架构
