## 💡 使用建议

### 考前准备（建议3周）

**第1周：背诵固定部分**
- **必须背诵**：摘要200字 + 背景150字 + 问题框架200字 + 效果180字 + 总结150字
- **总计约880字**，这部分在考场直接默写
- 每天背诵1小时，3天背熟，反复巩固

**第2周：理解核心技术**
- 理解7个主题的核心技术部分（每个约1000字）
- 不需要死记硬背，理解逻辑和关键点即可
- 每天精读1-2个主题，理解技术原理

**第3周：模拟演练**
- 手写模拟完整论文（计时2小时）
- 先默写固定部分，再发挥核心技术部分
- 检查字数控制和段落结构

### 考试应对（推荐写作顺序）

#### 写作策略（总计120分钟）

1. **审题构思**（5分钟）
   - 确定使用哪个主题
   - 回忆该主题的核心技术点

2. **默写固定部分**（30分钟）
   - 摘要200字（8分钟）- 默写+填架构名称
   - 背景150字（6分钟）- 直接默写
   - 问题200字（10分钟）- 默写框架+填5个问题
   - 效果180字（6分钟）- 先写好，放在草稿纸

3. **撰写核心技术**（70分钟）
   - 方案段120字（5分钟）
   - 核心技术1000字（60分钟）- 5个技术点，每个12分钟
   - 衔接过渡（5分钟）

4. **誊写效果总结**（10分钟）
   - 效果段180字（6分钟）- 从草稿纸誊写+调数据
   - 总结段150字（4分钟）- 默写+填要点

5. **检查修改**（5分钟）
   - 检查字数、数据一致性
   - 检查有无明显错误

### 临场应变

**如果题目不在准备范围：**
1. 找最接近的论文套用
2. 调整论文侧重点
3. 保证架构合理性和逻辑完整性
4. 多用量化数据证明效果

**套用技巧：**
- AI大模型 → 可以套用云原生或微服务架构
- 信创国产化 → 可以套用云原生架构改造
- 中台架构 → 套用微服务架构突出能力复用
- 安全架构 → 任意论文扩展安全设计部分
- Serverless → 套用云原生架构
