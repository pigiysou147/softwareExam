## 考试使用策略

### 考前准备（重点）
1. **必须背诵**（约680字，可以提前写好）
   - 摘要200字
   - 背景150字
   - 问题200字（框架固定，只需记住5个问题描述位置）
   - 效果180字
   - 总结150字

2. **理解记忆**（约1200字，考场发挥）
   - 准备3-7个主题的核心技术部分
   - 每个主题4-5个技术点
   - 理解逻辑，不必死记

### 考场写作（120分钟）
1. **审题**（5分钟）：确定主题
2. **摘要**（8分钟）：200字，默写+填空
3. **背景**（6分钟）：150字，直接默写
4. **问题**（8分钟）：200字，默写框架+填问题
5. **方案**（5分钟）：120字，填写方案名称和目标
6. **核心技术**（70分钟）：1200字，临场发挥（5段×200字）
7. **效果**（8分钟）：180字，默写+调数据
8. **总结**（6分钟）：150字，默写+填要点
9. **检查**（4分钟）

### 得分分布
- 摘要：10分
- 背景：10分
- 问题：10分
- 核心技术：50分 ← 最重要
- 效果：15分
- 总结：5分

## 各主题问题描述（填空用）

### 微服务架构
耦合度高修改一处需调整多处 / 扩展受限资源利用率低 / 部署风险高可用性不足 / 技术栈受限无法灵活选型 / 团队协作效率低集成周期长

### 云原生架构
资源利用率低CPU仅百分之二十五 / 缺乏弹性无法动态调整资源 / 部署效率低需五到七天人工操作 / 环境不一致测试通过生产出错 / 故障恢复慢平均需三10分钟

### 分层架构
业务复杂度高环节依赖关系复杂 / 团队规模大需明确职责划分 / 技术栈多样需合理组织方式 / 变更频繁需良好可维护性 / 质量要求高需满足高可用高性能

### 高可用架构
单点故障风险高组件故障系统不可用 / 故障恢复时间长人工修复超45分钟 / 跨区容灾能力弱本地机房灾难数据丢失 / 数据丢失风险大异步复制备份频率低 / 缺乏自动切换主备切换人工操作易出错

### 数据架构与治理
数据标准不统一编码定义互不兼容 / 数据质量差空值错值重复值质量仅百分之八十五 / 数据共享困难点对点开发周期长 / 数据血缘不清来源处理过程不明 / 数据安全隐患大缺乏访问控制和审计

### 大数据架构
数据处理能力不足仅支撑每秒一万条 / 实时性差批处理周期至少一小时 / 存储成本高冷数据占用高性能存储 / 计算效率低复杂查询需数小时 / 扩展困难单机数据库纵向扩展有限

### DevOps实践
发布周期长需求到上线平均两周 / 变更失败率高达15%提心吊胆 / 环境不一致开发测试通过生产报错 / 手工操作多编译打包部署靠人工 / 团队协作效率低开发运维各自为政
